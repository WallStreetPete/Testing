# Glossary

- Fork: Your personal copy of this repository on GitHub. You push branches to your fork and open pull requests back to the original repository.

- Upstream remote: A Git remote that points to the original repository you forked from (for this project: git@github.com:WallStreetPete/Testing.git). You fetch/merge from upstream to keep your local main branch current.

- Pull request (PR): A proposed set of changes from a branch (often on a fork) into the repository’s main branch. PRs are used for code review and CI checks before merging.
