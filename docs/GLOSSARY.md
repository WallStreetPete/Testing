# Glossary

- Fork: Your personal copy of this repository on GitHub. You push branches to your fork and open pull requests back to the original repository.

- Origin remote: The default Git remote name for the repository you cloned (typically your fork). You push your branches to origin.

- Upstream remote: A Git remote that points to the original repository you forked from (for this project: https://github.com/WallStreetPete/Testing.git). You fetch/merge from upstream to keep your local main branch current. In a fork-based workflow, origin points to your fork and upstream points to the original repo.

- Pull request (PR): A proposed set of changes from a branch within the same repository or from a fork into the repository’s main branch. PRs are used for code review and CI checks before merging.

- PR: Shorthand for pull request; see “Pull request (PR)” above.
