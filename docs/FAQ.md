# FAQ

- What is this repository?
  A minimal static website used for testing/demo, with simple HTML pages like home.html and about.html.

- How do I preview it locally?
  Open the HTML files directly in your browser or run a simple static server. See docs/SETUP.md for step-by-step commands.

- How do I contribute?
  Follow CONTRIBUTING.md: fork, create a branch, make changes, and open a pull request. There is currently no test suite or linter configured.

- Where do I report bugs?
  Open a GitHub issue.
